# JS Templates

Ready-to-use JavaScript templates for live coding interviews.

## Contents

- `interview-template.js` — Full cheat sheet with:
  - Parsing & string helpers
  - Arrays, sorting, Map, Set
  - Stack, Queue, Deque
  - Two pointers & Sliding window
  - Binary search + Lower bound
  - **MinHeap** & **MaxHeap**
  - **Union-Find (Disjoint Set)** with path compression + union by rank
  - BFS & DFS
  - Common string/regex ops
  - Complexity cheat-sheet
  - Interview flow checklist

## Usage

Copy the sections you need during the interview. Understand every line before using.
